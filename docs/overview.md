# プロジェクト概要書: デスクトップAIコンパニオン

## 1. ビジョンと開発目的

本プロジェクトは、デスクトップ常駐型AIコンパニオン（Neurosama風）を、**完全ローカル環境**かつ**低遅延・高応答性**で実現し、さらに **Godot Engine風の本格スタジオエディタ（shadcn/ui）** で全パラメータの調整・対話テスト・配信連携を一元管理できるプロクオリティのシステムを構築することを目的とする。

アバターレンダラーには、圧倒的な低GPU負荷とアニメ的愛嬌を誇る **Live2D をプライマリ（本命）** として採用。
日常のPC作業における透過デスクトップ常駐はもちろん、**OBS Studio Direct ブラウザソース連携** により、配信者やVTuberが緑背景不要の100%完全アルファ透過で高品質な共演配信を行える環境を提供する。

### コアコンセプト
1. **Live2D 本命の超低負荷設計**: GPU使用率数%で動作し、重いゲーム配信や作業中もPCの負荷を圧迫しない。
2. **Godot Engine 風 Studio UI (shadcn/ui)**: ノードツリー、ビューポート、インスペクター、コンソールを備え、全設定をリアルタイムに変更・テスト可能。
3. **OBS Direct 完全透過配信 & グリーンバック両対応**:
   - バックエンド内蔵HTTPサーバー（`:18923/avatar`）により、OBSにURLを貼るだけで緑フリンジ皆無の完全透過合成が可能。
   - もちろんビューポート上で緑背景（`#00FF00`）やマゼンタ（`#FF00FF`）のフルスクリーン描画も可能。
4. **どんなPCでも品質を落とさないLLM戦略 (Tier制)**:
   - VRAM 2GB〜4GB（またはCPUのみ）の 3B モデルから、標準の 7B、14B、クラウドフォールバックまで対応。
   - Few-Shot対話例の動的注入とGBNF文法制約により、小型モデルでも敬語化・キャラ崩壊を完全防止。
5. **プラガブル音声合成基盤**: VOICEVOX、Style-Bert-VITS2 等を自在に切り替え可能。
6. **完全ローカル・プライバシー保証**: 会話ログ、音声データ、メモリ情報は一切外部に送信されない。

## 3. 機能要件

### 3.1 Studio エディタ機能
- **4ペインレイアウト**:
  - **ノードツリー**: アバター、LLM、TTS、記憶、ウィンドウの構成一覧。
  - **ビューポート**: Live2D描画プレビュー、背景モード切替（透過チェッカー、緑、紫、黒）、視線テスト、リップシンクメーター。
  - **インスペクター**: スライダーによる感度・音量・推論温度・GPUレイヤー数の即時調整。
  - **下部パネル**: リアルタイム対話テストチャット、推論速度（tok/s）・遅延（ms）モニター、システムログ。
- **表示モード切替**: `Studio Mode` (エディタ) ↔ `Companion Overlay` (デスクトップ常駐) をワンクリック切替。

### 3.2 配信・OBS連携機能
- **OBS Direct ブラウザソース**: URL（`http://localhost:18923/avatar`）をOBSに追加するだけで完全透過表示。
- **グリーンバック / マゼンタフルスクリーン**: クロマキーキャプチャを行いたい環境向けに背景色単色表示もサポート。

   - 全体、フロント、バック、ライブラリ、Antigravityルールの完全策定。
